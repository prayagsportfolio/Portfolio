# **Project Portfolio**

## [Data Engineering & Risk Analytics: Accepted Loans Dataset](https://github.com/prayagsportfolio/Portfolio/tree/main/Data%20Engineering%20%26%20Risk%20Analytics%3A%20Accepted%20Loans%20Dataset)
