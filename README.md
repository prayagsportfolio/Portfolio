# **Project Portfolio**

## Data Engineering & Risk Analytics: Accepted Loans Dataset

This project demonstrates a complete ELT (Extract, Load, Transform) data pipeline and risk analysis of a real-world dataset for accepted personal and business loans.

## MBTI Personality Type Predictor

This project utilizes Machine Learning to predict an individual's Myers-Briggs Type Indicator (MBTI) personality based on demographic and psychometric data.

## Last Bite: Food Waste Management Platform

Last Bite is a comprehensive product management case study for a mobile application designed to bridge the gap between food waste and food insecurity.

## FieldSmARt: Augmented Reality (AR) Gardening Assistant

A product discovery project for a conceptual design of an **Augmented Reality (AR)** mobile application FieldSmARt, aimed at modernizing gardening and farming.

## Product Portfolio Optimization via Machine Learning

As a Corporate Consultant for company Griffith Foods, I developed a Machine Learning solution to optimize product lines and reduce manufacturing complexity.

## Airbnb Property Sales Dashboard

Designed a dashboard to analyze Airbnb property data to identify sales trends, optimal pricing strategies, and high-demand locations.

## Design and Fabrication of 1-Φ to 3-Φ Matrix Converter

1-Φ to 3-Φ Matrix Converter is a comprehensive electrical engineering project focused on the design, simulation, and hardware fabrication of a power converter topology.

## Code Breakers (Mastermind Clone)

"Code Breakers" is a Python-based command-line implementation of the classic strategy game Mastermind.

## Toyota Marketing & Advertisement Analysis

Designed a dashboard to provide a comprehensive analysis of Toyota's advertising and sales performance for the first quarter of 2021.
